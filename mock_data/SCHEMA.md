# QuantNova AI Synthetic HR Data Schema

All records are fictional. Employee IDs use the `QNA-` prefix.

- employees: employee_id, first_name, last_name, department, job_title, employment_type, location, hire_date, manager_id, employment_status.
- PTO: employee_id, pto_type, available_hours, accrual_rate_hours, as_of_date.
- benefits: employee_id, medical_plan, dental_plan, vision_plan, retirement_enrollment, status, as_of_date.
- mock tickets: ticket_id, employee_id, topic, summary, status, mock_action, created_at.
