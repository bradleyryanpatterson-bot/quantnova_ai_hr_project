# AI Tooling Log

AI-assisted coding may be used to draft, refactor, test, and document this QuantNova AI academic prototype. Team members remain responsible for reviewing generated code, validating citations and tool behavior, testing failure cases, protecting secrets, and ensuring that only synthetic QuantNova AI organizational data is committed.

For each meaningful AI-assisted change, record: date, task, tool used, files affected, human review performed, and test result.

We used ChatGPT for the requirements generation and then for the code generation.  The HR Handbook was created using an old employees handbook minus the propriotary data.
